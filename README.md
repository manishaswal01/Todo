# 🚀 Pro Task Manager (Todo App)

Ek modern aur clean "To-Do List" application jise **Glassmorphism UI** aur **Local Storage** ke saath banaya gaya hai. Is project ka main goal productivity ko visually appealing banana hai.

## ✨ Features
*   **Persistent Data**: Browser refresh karne par bhi aapka data delete nahi hoga (LocalStorage implementation)[cite: 3].
*   **Dynamic UI**: Har naye task ko ek unique random neon color assign hota hai[cite: 3, 4].
*   **Modern Design**: Glassmorphism effect, smooth animations, aur dark mode aesthetics[cite: 4].
*   **Accessibility**: Screen readers ke liye `aria-label` aur standard-compliant buttons[cite: 2].
*   **Responsiveness**: Mobile aur desktop dono par perfect kaam karta hai[cite: 4].

## 🛠️ Tech Stack
*   **HTML5**: Semantic structure ke liye[cite: 2].
*   **CSS3**: Modern layout, glassmorphism aur animations ke liye[cite: 4].
*   **JavaScript (ES6+)**: Task management logic aur storage handling ke liye[cite: 3].
